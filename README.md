# Тема 4. Домашня робота з Python

Репозиторій `goit-pycore-hw-03` містить чотири вправи. Для запуску достатньо Python 3 зі стандартною бібліотекою.

- `task_1.py` — `get_days_from_today(date)` повертає різницю в днях між сьогодні й заданою датою. Майбутня дата дає від’ємне число. Некоректний формат або неіснуюча дата викликає `ValueError`.
- `task_2.py` — `get_numbers_ticket(min, max, quantity)` повертає відсортовану випадкову вибірку унікальних чисел із діапазону `min…max` включно. Кількість має бути в межах `min…max` і не перевищувати розмір діапазону. За некоректних параметрів функція повертає `[]`.
- `task_3.py` — `normalize_phone(phone_number)` прибирає розділювачі та залишає цифри й один початковий `+`. Зберігає код, явно позначений `+`, додає `+` перед `380` і `+38` перед локальним номером.
- `task_4.py` — `get_upcoming_birthdays(users)` відбирає дні народження від сьогодні до шостого дня включно. Привітання із суботи й неділі переносяться на наступний понеділок, навіть якщо він за межами цього періоду. У невисокосний рік день народження 29 лютого враховується 28 лютого.

Приклад запуску з кореня репозиторію

```bash
python3 -c 'from task_3 import normalize_phone; print(normalize_phone("(050) 888-99-00"))'
```

Очікуваний результат — `+380508889900`.
